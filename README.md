# Patas & Amigos - Petshop

Projeto da disciplina **Fundamentos de Sistemas Web** (PUCRS Online) - Fase 1.

Site de um petshop fictício, feito apenas com **HTML** (sem CSS, Bootstrap ou JavaScript, conforme o enunciado da Fase 1).

## Páginas

- `index.html` - Início (apresentação do petshop)
- `produtos.html` - Produtos nas 3 categorias (acessórios, rações não perecíveis, higiene e limpeza), com foto, descrição e valor
- `servicos.html` - Serviços de banho e tosa, com e sem tele-busca
- `ajuda.html` - Arquivo de ajuda descrevendo as funcionalidades do site
- `imagens/` - Imagens usadas nas páginas

## Como ver o site

Abra o arquivo `index.html` no navegador, ou acesse pelo GitHub Pages.
